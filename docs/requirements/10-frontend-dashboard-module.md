# Module 10 — Frontend / Dashboard Module

## Purpose
User-facing UI for monitoring and configuration.

## Responsibilities
- Live option chain table, watchlist, alert configuration UI, charts, index
  selector.

## Functional Requirements
- FR1: Live option chain table with sortable columns.
- FR2: Watchlist management screen.
- FR3: Alert rule builder screen.
- FR4: Charts for IV/OI history (from Module 11 data).

## Non-Functional Requirements
- NFR1: Real-time UI updates without full page reload.
- NFR2: Responsive layout.

## Inputs / Outputs
- Input: REST/WebSocket APIs (Module 9).
- Output: rendered dashboard for end users.

## Dependencies
- Module 9.
